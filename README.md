# Calculatrice Web

Une calculatrice simple et élégante créée avec HTML, CSS et JavaScript vanilla.

## 📋 Description

Cette calculatrice permet d'effectuer des opérations mathématiques de base directement dans le navigateur. Le design est moderne et inspiré des calculatrices iOS.

## ✨ Fonctionnalités

- ✅ Opérations de base : addition, soustraction, multiplication, division
- ✅ Support des nombres décimaux
- ✅ Bouton AC (All Clear) pour réinitialiser
- ✅ Bouton DEL pour effacer le dernier chiffre
- ✅ Affichage du calcul en cours
- ✅ Support du clavier pour une utilisation rapide
- ✅ Design responsive et animations

## 🛠️ Technologies utilisées

- HTML5
- CSS3 (Grid Layout, Flexbox)
- JavaScript (Vanilla)

## 🚀 Comment utiliser

1. Clonez ce repository ou téléchargez les fichiers
2. Ouvrez le fichier `index.html` dans votre navigateur
3. Utilisez la souris ou le clavier pour effectuer vos calculs

### Raccourcis clavier :
- `0-9` : Chiffres
- `+, -, *, /` : Opérateurs
- `Enter` ou `=` : Calculer
- `Backspace` : Effacer
- `Escape` : Tout effacer
